## 🌌 Что внутри

- **Живая демка «текст → туманность»** — детерминированный процедурный генератор:
  фраза хешируется в сид (xmur3 → mulberry32) и превращается в уникальную туманность на canvas.
  Один текст = одна вселенная. Ползунки оттенка / энергии / звёзд, случайный сид, экспорт в PNG.
- **Звёздное поле** на canvas: параллакс, мерцание, метеоры, созвездия вокруг курсора.
- Печатающийся ротатор слов, анимированные счётчики, scroll-reveal, tilt-карточки со свечением.
- Прогресс-бар чтения, стеклянная навигация, мобильное бургер-меню, FAQ-аккордеон.
- Форма раннего доступа с тостами и салютом из частиц (локальная демка, ничего не отправляет).
- Доступность: prefers-reduced-motion, skip-link, aria-атрибуты, focus-visible, семантика.
- Адаптив от 320px до 4K. Шрифты Unbounded + Manrope (с системным фолбэком).

## 🚀 Запуск

Просто открой index.html в браузере — всё работает офлайн.
Деплой настроен на **GitHub Pages** (ветка main, корень репозитория).
